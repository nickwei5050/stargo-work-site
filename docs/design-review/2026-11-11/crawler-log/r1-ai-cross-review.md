# AI 交叉审核 2026-11-11

- 审核：agy CLI（gemini-4-argon-high）
- 范围：`origin/main...HEAD`
- 结论：**需修改**（request_changes，阻断项 2）

The Worker route pass-through and Analytics Engine logging structure are mostly sound, but substring-based bot/referrer matching introduces false positives and allows query-parameter metric pollution, totals are computed from a truncated LIMIT 100 result set, and failed or unavailable responses are served with public caching headers and raw backend error messages.

| 级别 | 位置 | 问题 | 建议 |
| --- | --- | --- | --- |
| major | ops/crawler-log/bots.mjs:3 | BOTS ends with short, generic tokens such as "Code", "nbot", "Muse", "Cursor", "Operator", "Instinct", "Trae", and "Spider", which classifyAgent() (ops/crawler-log/worker.mjs:30) matches via case-insensitive u.includes(low) with no token boundaries. Any User-Agent containing "code" (e.g. VSCode, Xcode) or ending in "nbot" (e.g. LinkedInBot, msnbot, TurnitinBot, ProtonBot) is misclassified as an AI bot, inflating bot counts and skipping aiReferral tracking on line 66. | Require word/delimiter boundaries when matching short or ambiguous tokens in classifyAgent(), or remove/qualify overly generic 4-letter tokens in BOTS. |
| major | ops/crawler-log/worker.mjs:34-39 | aiReferral() checks src.includes(needle) against the raw concatenated Referer and utm_source string instead of parsing the referrer hostname, so short needles in AI_REFERRERS like "you.com", "grok.com", "poe.com", and "kimi.com" falsely match unrelated domains (e.g. thankyou.com, ngrok.com). In addition, line 37 returns up to 40 raw characters of any utm_source starting with chatgpt\|perplexity\|claude\|..., allowing arbitrary campaign suffixes or crafted query strings to create unbounded high-cardinality entries in VISITS and pollute the public /api/crawlers response. | Parse the Referer header with new URL() and match hostname (equal to or subdomain of the target domain, plus path check for bing.com/chat), and normalize regex-matched utm_source values to canonical provider names instead of storing the raw query parameter slice. |
| minor | ops/crawler-log/worker.mjs:98-123 | out.totals is calculated in JavaScript by summing out.agents, which is capped at LIMIT 100 in the SQL query on line 98. Because BOTS defines 207 bots plus AI referral sources, any window with more than 100 active (kind, name, operator, category) tuples will silently undercount totals. | Compute category totals via a dedicated SQL query grouped by blob1 and blob4 (which has fewer than 10 combinations), or increase the agents limit to cover all known bots and referrers. |
| minor | ops/crawler-log/worker.mjs:110, 138-143 | handleCrawlers() always sets Cache-Control: public, max-age=600 even when status is 502 or body.available is false, allowing CDN edges and browsers to cache transient failures for 10 minutes. It also exposes raw exception and SQL error strings (errors[names[i]] and error) on a public CORS (*) endpoint. | Use Cache-Control: no-store when status !== 200 or !body.available, and log detailed SQL exceptions via console.error while returning a generic error message in the public JSON response. |
