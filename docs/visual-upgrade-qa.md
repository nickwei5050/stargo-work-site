# STARGO WORK · 图片与交互升级验收

日期：2026-09-05。以下为本轮实际执行的本地验证；线上发布检查另以发布记录为准。范围：内容视觉替换、视频恢复、切换可靠性及生产适配，不冒充战略重做或无障碍认证。

## 发现与修正

- 旧 HTML/CSS 界面示意缺乏统一视觉。按既有黑白、钛银、铜色，逐张生成 43 个独立业务场景、概念结构和角色。
- 图片散落正文、菜单、共享组件、CSS 背景及分享元数据。增加清单和构建末端映射，中英文同步，保留模板元素、类名和动效目标。
- 换图时发现 sizes=auto 使部分自动宽度图片退化成 300px 固有宽度；改用明确响应式尺寸，卡片恢复完整宽度。
- 四栏原受 IX2 与脚本竞争控制。改为单一 ScrollTrigger/Lenis 控制器；保持淡入淡出、滚动切换和移动折叠，增加键盘、resize 清理和布局刷新。
- 首页网格中心恢复第四模板银色轨道影片；保留缩放、叠字、遮罩，增加播放/暂停、离屏暂停、减少动态效果偏好及稳定失败提示。
- 悬浮 Logo 的 # 修正为对应语言首页；CSS/JS URL 加内容版本，新图用独立目录，避免旧缓存。
